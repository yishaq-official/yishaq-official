## ⚡ Who Am I?

I'm a **Full Stack Developer** based in **Addis Ababa, Ethiopia**, passionate about building systems that solve real problems — from university management tools and gym platforms to AI-powered recommendation agents and computer vision systems. I move comfortably across the stack: low-level concurrency in Java, scalable REST APIs in Node.js, clean UIs in React, and robust data pipelines across multiple database engines.

- 🔭 **Current Focus:** Scaling **UniFix**, a C# maintenance-request & reporting platform for university environments.
- 🧠 **Deep Dive:** Thread Synchronization in Java and AI Logical Inference (constraint-based planning).
- 🐧 **Daily Driver:** Linux Mint — because owning your environment matters.
- 💬 **Ask me about:** Java concurrency, scalable APIs, multi-database architecture, or computer vision.
